# Сайт-визитка с заявками в Telegram

**Живая версия:** https://artem-portfolio-xywf.onrender.com

Одностраничный лендинг: тёмная тема, адаптивная вёрстка, форма заявки.
Заявки приходят прямо в Telegram.

## Запуск

```powershell
npm install    # один раз
npm start      # http://localhost:8000
```

Нужен Node.js 20.12+. Сервер раздаёт файлы сайта и обрабатывает форму.

## Настройка Telegram (один раз)

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot`.
2. Скопируйте токен вида `1234567890:AAH...`.
3. Напишите своему боту любое сообщение (иначе он не сможет писать первым).
4. Скопируйте `.env.example` в `.env` и заполните:

```
TELEGRAM_BOT_TOKEN=1234567890:AAH...
TELEGRAM_CHAT_ID=123456789
```

`chat_id` можно узнать так: откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` после сообщения боту —
поле `message.chat.id`.

5. Перезапустите `npm start`.

Проверка: `http://localhost:8000/api/health` → `{"ok":true,"telegramConfigured":true}`

### Если Telegram не открывается напрямую

В России `api.telegram.org` часто заблокирован. Если у вас запущен
VPN-клиент с HTTP-прокси, добавьте в `.env`:

```
HTTPS_PROXY=http://127.0.0.1:10809
```

Сервер сам подхватит прокси. На хостинге эти строки не нужны — удалите их.

## Структура

```
.
├─ index.html      разметка страницы
├─ styles.css      оформление (цвета — в блоке :root в начале файла)
├─ script.js       валидация формы + анимации появления
├─ server.js       сервер: статика + POST /api/lead → Telegram
├─ cases/          демо-проекты для портфолио
│  ├─ coffee/      лендинг кофейни (дизайн, адаптив)
│  ├─ calculator/  калькулятор стоимости сайта (логика, отправка заявки)
│  └─ dashboard/   дашборд заказов (поиск, фильтры, CSV)
├─ .env            секреты (НЕ в git)
├─ .env.example    шаблон настроек
└─ README.md
```

## Что менять в первую очередь

| Что | Где |
|---|---|
| Имя, заголовок, описание | `index.html`, блок `.hero` |
| Цвета и шрифт | `styles.css`, блок `:root` |
| Навыки | `index.html`, блок `.skills` |
| Проекты | `index.html`, блок `.cards` |
| Тексты секций | `index.html`, секции `#about`, `#projects` |

## Безопасность

- Токен бота хранится только в `.env`, который в `.gitignore`.
- В браузер токен не попадает: заявку шлёт сервер.
- **Honeypot**: скрытое поле `website`, которого человек не видит. Бот его
  заполняет — заявка молча отбрасывается (боту всё равно отвечаем `ok`).
- **Проверка времени**: заявка, отправленная быстрее 1.5 секунды после
  открытия страницы, считается скриптом и отбрасывается.
- **Rate limit**: 5 заявок с одного IP за 10 минут.
  Настраивается в `.env`: `RATE_LIMIT_MAX`, `RATE_LIMIT_WINDOW_MIN`.
- Размер тела запроса ограничен 10 КБ, длина полей обрезается.
- Текст экранируется перед отправкой в HTML-разметку Telegram.

## Публикация в интернете

Нужен хостинг, который умеет запускать Node.js (не просто статику):

- **Render.com** — бесплатный тариф, деплой из репозитория.
- **Railway** — бесплатный пробный период.
- **Свой VPS** — если хочется полного контроля.

Для чисто статической версии без формы подойдут Cloudflare Pages или
Netlify, но тогда заявки работать не будут.
