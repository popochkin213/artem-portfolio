# Сайт-визитка разработчика

Одностраничный лендинг: тёмная тема, адаптивная вёрстка, форма заявки
с валидацией. Без сборки, без зависимостей — чистые HTML, CSS и JS.

## Запуск

Просто откройте `index.html` двойным кликом в браузере.

Или через локальный сервер (нужен Python):

```powershell
python -m http.server 8000
```

Затем откройте http://localhost:8000

## Структура

```
.
├─ index.html    разметка страницы
├─ styles.css    оформление (цвета — в блоке :root в начале файла)
├─ script.js     валидация формы + появление секций
└─ README.md
```

## Что менять в первую очередь

| Что | Где |
|---|---|
| Имя, заголовок, описание | `index.html`, блок `.hero` |
| Цвета и шрифт | `styles.css`, блок `:root` |
| Навыки | `index.html`, блок `.skills` |
| Проекты | `index.html`, блок `.cards` |
| Тексты секций | `index.html`, секции `#about`, `#projects` |

## Как получать заявки в Telegram

Сейчас форма работает в демо-режиме: проверяет поля и показывает
«отправлено», но никуда не отправляет.

Чтобы заявки приходили в Telegram:

1. Создайте бота через [@BotFather](https://t.me/BotFather) → получите токен.
2. Узнайте свой `chat_id` (напишите боту, откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. Токен **нельзя** держать в `script.js` — он виден всем. Нужна
   серверная функция (например, Cloudflare Worker или Vercel Function),
   которая принимает POST и вызывает `sendMessage`.
4. Пропишите её адрес в `script.js`:

```js
const CONFIG = {
  endpoint: '/api/lead',
  // ...
};
```
